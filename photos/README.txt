Папка для фотографий автомобилей.

Как пользоваться:
1. Бросайте сюда файлы фото. Имена лучше давать по ID автомобиля:
     1_1.jpg, 1_2.jpg, 1_3.jpg   (ID 1, фото 1/2/3)
     25_1.jpg, 25_2.jpg          (ID 25)
2. Отправьте их на GitHub: запустите publish_photos.cmd в папке репозитория.
3. Ссылка на фото для колонки "Фото" в таблице:
     https://cdn.jsdelivr.net/gh/89501116752/privoz-catalog@main/photos/1_1.jpg

Несколько фото в одной строке таблицы (через |):
     .../photos/1_1.jpg|.../photos/1_2.jpg|.../photos/1_3.jpg

Первое фото становится обложкой карточки, остальные открываются в галерее.

Рекомендуется сжимать фото перед загрузкой:
  - ширина ~1200 px
  - размер ~150-300 КБ
Формат: .jpg или .webp
